## 🛣️ **Roadmap شاملة لتعلم Data Analysis:**

---

### 🔹 **المرحلة 1: الفهم الأساسي (Foundations)**  
#### ✅ المطلوب:
- فهم أساسيات **البيانات**
- الفرق بين **Data Analyst vs Data Scientist vs Data Engineer**
- أنواع البيانات: Structured vs Unstructured

---

### 🔹 **المرحلة 2: Excel & Google Sheets (تحليل البيانات البسيط)**
#### ✅ تتعلم:
- استخدام **Pivot Tables**
- **VLOOKUP / XLOOKUP / INDEX-MATCH**
- تحليل البيانات المالية أو البيعية
- الرسم البياني البسيط (Line, Bar, Pie)

#### 📘 مصادر:
- كورسات Excel على Udemy أو YouTube (مثل قناة ExcelIsFun)

---

### 🔹 **المرحلة 3: SQL – لغة قواعد البيانات**
#### ✅ تتعلم:
- `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `JOIN`
- التعامل مع قواعد البيانات مثل MySQL أو PostgreSQL

#### 📘 مصادر:
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/)
- كورس "SQL for Data Analysis" على Udemy

---

### 🔹 **المرحلة 4: Python for Data Analysis**
#### ✅ تتعلم:
- مكتبات مثل:
  - `pandas`: لتحليل البيانات
  - `numpy`: للمعادلات الرياضية
  - `matplotlib` و `seaborn`: للرسم البياني
- التعامل مع ملفات CSV و Excel
- التحليل الإحصائي البسيط

#### 📘 مصادر:
- كورس [Python for Data Analysis by Data School](https://www.dataschool.io/)
- قناة Amr Elshamy أو Elzero

---

### 🔹 **المرحلة 5: تصور البيانات (Data Visualization)**
#### ✅ أدوات:
- **Power BI** أو **Tableau**
- Python: باستخدام `matplotlib`, `seaborn`, `plotly`

#### ✅ مهارات:
- اختيار النوع المناسب من الرسوم البيانية
- بناء Dashboards تفاعلية
- KPI Tracking

---

### 🔹 **المرحلة 6: الإحصاء التطبيقي (Applied Statistics)**
#### ✅ تتعلم:
- **Descriptive Statistics**: mean, median, std
- **Probability Basics**
- **Correlation vs Causation**
- A/B Testing

---

### 🔹 **المرحلة 7: مشاريع عملية (Portfolio Building)**
#### ✅ أفكار مشاريع:
- تحليل بيانات مبيعات
- Dashboard لبيانات كورونا
- تحليل بيانات العملاء من e-commerce
- مشروع باستخدام Power BI + Excel + Python + SQL

#### 📘 أدوات نشر المشاريع:
- GitHub
- LinkedIn
- Kaggle

---

### 🔹 **المرحلة 8: التقديم على الوظائف**
#### ✅ جهّز:
- CV مخصص للـ Data
- Portfolio فيه مشاريعك
- حساب قوي على LinkedIn
- تمرّن على أسئلة Interviews في SQL و Excel

---

## 🧰 أدوات هتحتاجها طول الطريق:
- Excel / Google Sheets
- SQL (MySQL, PostgreSQL)
- Python (Jupyter Notebook)
- Power BI أو Tableau
- GitHub
